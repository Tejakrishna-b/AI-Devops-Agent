# AI DevOps Agent Workflow

User Prompt / Jira Ticket
      ↓
AI DevOps Agent
      ↓
Analyze Requirement
      ↓
Locate Repositories
      ↓
Generate Changes
      ↓
Create Branch
      ↓
Add Code / Terraform / Config
      ↓
Commit Code
      ↓
Create Pull Request
      ↓
Developer Review
      ↓
Merge
      ↓
Automatic Deployment

---

This agent automates:
- Upgrading SonarQube or other software by prompt or Jira ticket
- Reading Jira tickets and analyzing issues
- Creating branches in repositories
- Generating required code, Terraform, and config files
- Committing and raising PRs
- Deploying after PR review and merge
- Creating infrastructure as needed

No manual steps required; the agent handles the full DevOps workflow.
