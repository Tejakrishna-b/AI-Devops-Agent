# Java 11 to Java 21 Upgrade Guide

## Overview
This guide helps you upgrade your project from Java 11 to Java 21.

## What's Changed in Java 21
- **LTS Release**: Java 21 is a Long-Term Support (LTS) release
- **New Features**: Virtual Threads, Pattern Matching, Record Patterns, String Templates (Preview)
- **Performance**: Improved GC, faster startup times
- **Removed Features**: Some deprecated APIs from Java 11 removed

## Upgrade Steps

### 1. Update Build Configuration

#### Maven (pom.xml)
```xml
<properties>
    <maven.compiler.source>21</maven.compiler.source>
    <maven.compiler.target>21</maven.compiler.target>
    <java.version>21</java.version>
</properties>
```

#### Gradle (build.gradle)
```gradle
java {
    sourceCompatibility = JavaVersion.VERSION_21
    targetCompatibility = JavaVersion.VERSION_21
}
```

#### Gradle Kotlin DSL (build.gradle.kts)
```kotlin
java {
    sourceCompatibility = JavaVersion.VERSION_21
    targetCompatibility = JavaVersion.VERSION_21
}
```

### 2. Update Docker Configuration

#### Dockerfile
```dockerfile
# Before
FROM openjdk:11-jre-slim

# After
FROM eclipse-temurin:21-jre-alpine
```

### 3. Update CI/CD Configuration

#### GitHub Actions (.github/workflows/build.yml)
```yaml
- name: Set up JDK 21
  uses: actions/setup-java@v3
  with:
    java-version: '21'
    distribution: 'temurin'
```

#### Jenkins (Jenkinsfile)
```groovy
tools {
    jdk 'JDK 21'
}
```

### 4. Install Java 21 Locally

#### macOS (using Homebrew)
```bash
brew install openjdk@21
sudo ln -sfn /opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk
```

#### Ubuntu/Debian
```bash
sudo apt update
sudo apt install openjdk-21-jdk
sudo update-alternatives --config java
```

#### Windows (using Chocolatey)
```powershell
choco install openjdk --version=21
```

### 5. Verify Java Version
```bash
java -version
# Should show: openjdk version "21.x.x"
```

### 6. Update Dependencies

Check and update dependencies that may need Java 21 compatible versions:
```bash
# Maven
mvn versions:display-dependency-updates

# Gradle
./gradlew dependencyUpdates
```

### 7. Test Your Application

Run comprehensive tests:
```bash
# Maven
mvn clean test

# Gradle
./gradlew clean test
```

### 8. Common Issues & Solutions

#### Issue: Illegal Reflective Access Warnings
**Solution**: Add JVM arguments:
```bash
--add-opens java.base/java.lang=ALL-UNNAMED
```

#### Issue: Deprecated API Usage
**Solution**: Replace deprecated APIs with modern alternatives:
- `new Date()` → `LocalDate.now()`
- `StringBuffer` → `StringBuilder`

#### Issue: Module System Conflicts
**Solution**: Add module dependencies in `module-info.java`

### 9. Update IDE Configuration

#### IntelliJ IDEA
1. File → Project Structure → Project
2. Set Project SDK to Java 21
3. Set Language Level to "21 - Pattern matching for switch"

#### Eclipse
1. Window → Preferences → Java → Installed JREs
2. Add Java 21 JRE
3. Set as default

#### VS Code
Update `.vscode/settings.json`:
```json
{
    "java.configuration.runtimes": [
        {
            "name": "JavaSE-21",
            "path": "/path/to/jdk-21"
        }
    ]
}
```
